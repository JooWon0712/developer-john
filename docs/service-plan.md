# 서비스 구현과 후속 기획

기준일: 2026-10-30.

## 공통 언어 지원과 현재 검증

한국어 주소와 대응하는 영어 `/en`, `/en/services`, `/en/projects`, `/en/discovery/ikigai`, `/en/services/game/...` 경로를 제공한다. `/about`은 `/`로, `/en/about`은 `/en`으로 이동하며 영어 404 화면도 제공한다. 서비스 목록에는 게임·디비전2만 등록하고 이키가이는 양쪽 직접 주소에서 사용할 수 있다.

공통 헤더의 한국어·English 선택 한 곳을 사용한다. 로고·내부 메뉴·카드·경로 탐색은 현재 언어를 유지하고, 언어를 바꿀 때 현재 쿼리와 해시를 보존한다. 언어는 URL로 유지하며 쿠키 저장이나 선호 언어에 따른 자동 리디렉션은 제공하지 않는다. `src/lib/i18n.ts`의 공통 경로 도우미와 `pageMetadata`가 언어별 주소·canonical·hreflang·Open Graph 로케일을 관리한다. 푸터·맨 위로 이동·본문 바로가기와 접근성 안내도 현재 언어에 맞춘다.

루트 서버 HTML은 기본 `lang="ko"`이며, 영어 레이아웃의 서버 `lang="en"` 영역 안에 영어 페이지를 표시한다. 공통 헤더가 클라이언트에서 현재 경로에 맞춰 `<html lang>`을 동기화한다.

새 경로를 반영한 프로덕션 빌드는 정적 경로 17개와 영어 404용 동적 경로를 생성하며 성공했다. 자동 테스트는 레드 문 19개·이키가이 18개·공통 언어·등록 경로 5개·Analytics 3개, 총 45개가 통과했다. 디비전2 서비스와 이벤트의 새 경로 등록 회귀 테스트를 포함한다. 저장 관련 테스트는 메모리 대체 객체를 사용하며 Analytics 테스트도 실제 GA 서버에 요청하지 않는다. 아래의 초기 구현 확인 이력은 현재 검증과 구분한다.

한국어·영어 디비전2 목록·상세 4개 새 주소의 HTTP 200과 새 canonical을 확인했다. 이전 주소의 308 이동에서 쿼리가 보존되었다. 인앱 브라우저에서 서비스 카드 → 목록 → 이벤트의 새 경로 이동, 이전 영어 이벤트 주소의 쿼리·보상 해시 보존, 전역 언어 링크의 쿼리·해시 동시 보존을 확인했다. 한국어·영어 목록의 320px 화면은 clientWidth와 scrollWidth가 모두 305px로 가로 넘침이 없었다.

레드 문 상세의 터미널 통합 후 TypeScript 검사와 프로덕션 빌드가 성공했으며 정적 경로 17개를 유지했다. 인앱 브라우저에서 한국어·영어 상세를 320px로 확인했으며 clientWidth와 scrollWidth가 모두 305px로 가로 넘침이 없었다. 한국어 검색 결과는 `관리자` 2개·`핏빛 사냥개` 5개였고, 폭 560px 유니폼 확대 대화상자가 최상위 레이어에서 프레임에 잘리지 않고 열리고 닫혔다. 스크롤 후 카테고리 사이드바가 상단 24px에 고정되는 것도 확인했다. 검색 해제·모두 접기로 복귀했고 개인 보상 체크는 변경하지 않았다. 이번 스타일 변경 후 단위 테스트는 재실행하지 않았으며 기존 45개 통과 결과를 유지한다.

경로 변경 전 인앱 브라우저에서 영어 홈 → 서비스 → 디비전2 → 레드 문 이동의 영어 주소 유지, 공통 언어 선택 1개, 한국어 → 영어 전환의 쿼리·해시 보존을 확인했다. 영어 이미지 대체 설명·진입 문구·푸터와 390px 모바일 폭의 왼쪽 정렬도 확인했다. 개인 체크·메모 및 브라우저 저장소를 직접 변경하지 않았으며, 저장 동작의 자동 테스트와 화면 검증을 구분한다.

## GA4와 공개 준비

도메인 구매는 사용자가 확인했다. DNS 연결·HTTPS 설정·사이트 공개는 아직 완료하지 않았다. 사용자 제공 화면에서 GA4 웹 스트림 `developer-john Web`, 설정 URL `https://developer-john.com/`, 측정 ID `G-17PE2KX72Q`를 확인했다.

설치 코드는 루트 레이아웃의 클라이언트 래퍼와 `next/script`의 `afterInteractive`를 사용한다. 프로덕션 실행이면서 실제 origin이 `https://developer-john.com` 또는 `https://www.developer-john.com`과 정확히 일치할 때만 GA4를 로드한다. 로컬·개발·미리보기·HTTP·다른 포트에서는 로드하지 않는다.

초기화 `config`는 한 번 등록하고 수동 `page_view`는 추가하지 않는다. SPA 경로 전환 측정은 GA4 향상된 측정의 브라우저 기록 변경 설정에 의존한다. 사용자 개인 답변·메모·보상 체크 내용을 전송하는 커스텀 이벤트는 추가하지 않았다.

`node --test scripts/test-analytics.mjs`의 3개 테스트는 운영 origin 제한, 로컬·미리보기·HTTP·다른 포트 차단, 기존 대기열 보존과 단일 초기화 명령을 검증하며 통과했다. 실제 GA 계정 조작과 수집 요청을 발생시키는 QA는 수행하지 않았다. 운영 데이터 수신과 SPA 조회 누락·중복은 DNS·HTTPS·공개 완료 후 확인한다.

광고 스크립트와 광고 계정·슬롯 연동은 아직 구현하지 않았다. 넓은 화면의 선택적 좌우 영역과 본문 폭을 유지하는 공통 레이아웃만 준비되어 있다. 광고 내용이 없으면 빈 광고 요소를 생성하지 않는다.

### 화면 스타일

사이트 공통 화면과 보상 서비스는 네이비 바탕·샌드 강조색, 고정폭 글꼴, 2~4px 모서리의 CLI 테마를 사용한다. 로고와 파비콘은 네이비·샌드 커서형 JW(E-05)다. 명령어 형태의 문구는 시각 장식이며 실제 입력창이나 실행 기능을 제공하는 것으로 표시하지 않는다. Linux 사용자 표시는 `john`, 홈·서비스·디비전2의 표시 경로는 `/home/john`, `/home/john/services`, `/home/john/services/game/the-division-2`, 홈 프롬프트는 `john:~$`를 사용한다. 홈·서비스 주소는 `/`, `/services`이며 디비전2는 `/services/game/the-division-2` 계층을 사용한다. `developer-john` 브랜드·도메인은 유지한다.

서비스 카드에는 실제 기본 주소의 `/services`만 생략한 `/game/the-division-2`와 카테고리를 표시하고, 언어별 주제명은 접근성 이름으로 유지하며 기능 설명을 제공한다. 영어 화면에서도 표시 경로는 같으며 실제 링크는 한국어 `/services/game/the-division-2`, 영어 `/en/services/game/the-division-2`를 유지한다. 이키가이를 다시 목록에 등록할 때도 `/discovery/ikigai` 형식을 사용한다. 완성된 서비스 카드는 전체를 하나의 링크로 제공하고 별도 진입 버튼은 표시하지 않는다. 링크의 접근성 이름은 카드 제목과 기능 이름을 참조한다. 디비전2 이벤트 카드는 `redMoon.slug`를 디렉토리명으로 사용해 `./red-moon-unleashed-2026/`와 한국어·영어 이벤트 이름을 함께 표시한다. 두 언어 모두 이벤트 카드 전체를 해당 보상 가이드 링크로 제공하며 별도 가이드 보기 버튼은 표시하지 않는다. 디비전2 목록과 상세는 전체 경로를 나열하는 breadcrumb 없이 제목 표시줄과 ls/cat 명령줄로 현재 경로를 표현한다. 본문 첫 부분에는 상위 목록 링크 하나를 제공한다.

예를 들어 '게임하기'를 좋아하는 태그로 고르면 **게임 입문 팁 만들기**가 관심을 넓혀볼 후보가 될 수 있다. 직접 해본 일에서 '설명하기'도 골랐다면 그 연결을 경험 근거로 보여준다. 실험은 '30분 동안 익숙한 게임의 입문 팁 5개를 적고 한 사람에게 이해하기 쉬운지 물어보기'다.

실험 후에는 해봤는지와 함께 '하는 동안 즐거웠나요 / 다시 해보고 싶나요 / 누군가에게 도움이 됐나요' 세 질문 및 최대 500자 메모를 기록한다. 후기와 자유 메모는 원문으로 보관하며 추천 순서를 자동 변경하지 않는다.

### 저장과 구현 범위

계정·서버 DB·LLM 없이 정적 데이터와 브라우저 계산으로 동작한다. 저장 키는 `developer-john:discovery:ikigai:v1`이다. 스키마 1의 질문 단계·결과 화면 여부·목표·시간·선택 태그·보상 답변·메모·활동별 후기·저장 시각을 브라우저에 자동 저장한다. 다른 탭의 같은 서비스 기록 변경·삭제를 반영하며, 서비스 기록 삭제는 이 키만 제거한다. 디비전2 등 다른 서비스 기록은 유지한다.

최초 저장 읽기 전에는 쓰기를 막는다. 잘못된 스키마·ID·답변·메모 길이 등으로 손상된 기록은 자동으로 덮어쓰지 않고 명시적 삭제 전까지 보존한다. 저장소 차단·용량 부족 등 실패 시 안내하고 현재 화면의 입력은 유지한다. 브라우저 데이터 삭제나 다른 기기에서는 같은 기록이 보장되지 않으며, 서버 전송과 기기 간 동기화는 제공하지 않는다.

### 검증

`node --test scripts/test-ikigai.mjs`의 자동 테스트 18개가 통과했다. 빈 답변의 일반 탐색, 선택·목표·시간에 따른 순서, 실제 선택과 일치하는 근거, 보상 답변의 순위 중립성, 메모 미해석, 상태 복원과 손상 원본 보호, 저장 실패·이벤트 처리에 더해 영어 문구 완성도·언어별 추천 불변·보상 문구의 조건·저장 형식 및 사용자 원문 보존을 확인한다. 전체 45개 테스트와 현재 빌드 결과는 공통 검증 항목에 정리했다. 저장소는 메모리 대체 객체이며 실제 브라우저 저장소 테스트는 아니다.

브라우저에서는 두 언어의 6단계 이동·건너뛰기·수정, 결과와 후기, 새로고침 복원, 두 탭 변경·삭제, 모바일 폭·키보드 조작 및 저장 실패 안내를 확인해야 한다. 이키가이 질문·결과·후기의 조작은 이번 브라우저 확인 범위에 포함하지 않았다.

### 초기 구현 확인 이력

초기 구현 당시 화면을 포함한 TypeScript 검사와 프로덕션 빌드를 통과했다. 실행 중인 서버에서 홈·서비스 목록·취향 찾기·디비전2 페이지의 HTTP 200, 취향 찾기 canonical·현재 메뉴·초기 입력 비활성화와 당시 서비스 진입 링크를 확인했다. 당시 디비전2 회귀 테스트와 합쳐 총 33개 테스트가 통과했다. 현재 서비스 목록에는 이키가이 진입 링크를 표시하지 않으며 직접 주소는 유지한다. 이 초기 검증에도 실제 브라우저 화면 조작은 포함하지 않았다.
