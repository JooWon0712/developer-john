# 개인정보처리방침 운영 기준

한국어 `/privacy`와 영어 `/en/privacy`는 현재 사이트의 보상 기록, GA 방문 통계, 이메일 문의만 설명합니다. 준비 중 서비스나 미구현 광고는 포함하지 않습니다.

## 확정한 기준

아래 계정·운영 설정은 사용자 확인에 근거합니다. 외부 계정에 직접 접속해 검증하거나 변경한 결과는 아닙니다.

| 항목 | 기준 |
| --- | --- |
| 문의 창구 | `devjw0712@gmail.com`, 운영자가 직접 대응 |
| 문의 메일 보관 | 마지막 응대 완료일부터 1년. 같은 문의의 후속 응대가 있으면 마지막 후속 응대 완료일부터 계산 |
| 문의 메일 삭제 | 기간이 지난 메일을 Gmail 휴지통에서도 영구 삭제. 첨부파일을 별도로 저장했다면 함께 삭제 |
| 문의 계정 보호 | 운영자 본인만 메일함 접근, Google 계정 2단계 인증 사용 |
| 별도 백업 | 만들 계획 없음 |
| 개인정보 요청 | 같은 이메일로 접수하고 필요한 범위에서 본인·대리인 확인 후 관련 법령에 따라 조치·결과 회신 |
| GA 보관 | 이벤트·사용자 데이터 각각 14개월, 새 활동에 따른 사용자 보관기간 재설정 끄기 |
| GA 수집·광고 설정 | 세부 위치·기기 수집 및 광고 개인 최적화 끄기, 계정의 선택적 데이터 공유 4개 모두 해제 |
| GA 제품 연결 | 연결한 제품 없음 |
| 보상 기록 | 브라우저 `localStorage`에만 저장, 서버·GA 전송 없음. 자동 만료기간 없음 |

GA는 공개 운영 도메인의 프로덕션 실행에서만 로드됩니다. 보관 설정은 표준 집계 보고서 전체나 쿠키의 유효기간과 다릅니다. 문의 메일 삭제는 운영자가 수행할 기준이며 자동 삭제 기능은 없습니다. 자동 전달과 첨부파일의 개별 저장 여부는 확정하지 않았습니다.

## 초기 운영 범위

실제로 처리하는 정보에 맞춰 간결하게 안내합니다. 선택적 권장 사항을 필수 절차처럼 추가하지 않습니다. 동의 배너·푸터 통계 설정은 보류하며 기존 GA 실행 조건은 유지합니다.

공개 페이지의 초안 경고, 미확정 사항 반복 안내와 상세 4단계 요청 절차는 덜어냈습니다. 작성일은 2026년 10월 30일이며 시행일을 임의로 정한 것은 아닙니다. 검색용 `noindex, follow`는 공개 전 설정으로 유지합니다.

## 공개 직전에 확인할 내용

- 운영자 표시: 실명 공개 결정은 보류. 실제 운영 형태에 맞는 최종 표시 정보 확인.
- 배포 환경: 웹서버·프록시 등의 실제 접속 로그 기록 여부, 항목·목적·보관·삭제·접근 범위 확인.
- Google 서비스: 실제 GA·Gmail 이용에 적용되는 처리 관계와 국외 이전 안내, GA의 남은 수집 설정 확인.
- 운영 조건: 적용되는 요청 처리 기한·동의 요건을 필요한 범위에서 확인하고 시행일·검색 노출 설정 결정.
