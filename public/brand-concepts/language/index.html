언어 선택 시안

A 명령어형을 추천합니다. 현재의 Linux 경로 탐색과 같은 문법으로 읽힙니다.
각 시안의 버튼을 누르면 해당 시안의 데스크톱·모바일 선택 상태가 함께 바뀝니다.

OPTION A추천

명령어형

헤더의 Linux 경로와 자연스럽게 이어집니다. 두 언어를 바로 비교하고 선택할 수 있어 추천합니다.

가벼운 강조 · 두 언어가 항상 보임

현재 선택: 한국어

OPTION B

분할 버튼형

선택된 언어가 면으로 또렷하게 드러납니다. 익숙한 버튼 형태를 선호할 때 어울립니다.

분명한 선택 상태 · 버튼의 존재감이 큼

현재 선택: 한국어

OPTION C

현재 언어 드롭다운

헤더 공간을 가장 적게 차지합니다. 언어를 바꾸려면 목록을 한 번 열어야 합니다.

공간 절약 · 목록을 열어 다른 언어 확인

현재 선택: 한국어

Tab으로 이동하고 Enter·Space로 선택할 수 있습니다. C는 방향키로 언어를 고르고 Esc로 닫을 수 있습니다.
