# 다크 모드 시안 v1

다섯 가지 팔레트를 현 사이트의 헤더·소개·터미널 그림·서비스 카드에 적용해 비교하는 독립 정적 페이지입니다. 사이트 본체나 실제 테마 설정을 변경하지 않습니다.

- 진입 경로: `/brand-concepts/dark-mode-v1/index.html`
- 1. 깊은 바다 청록 — 추천
- 2. 잉크 네이비 + 샌드
- 3. 차콜 + 세이지
- 4. 에스프레소 + 앰버
- 5. 슬레이트 + 라벤더

각 안의 `크게 보기`는 키보드 Esc로 닫을 수 있는 대화상자를 엽니다. 낮/밤 전환은 모든 시안에 함께 반영되며 저장되지 않습니다. 밤 그림은 웜뱃이 안경을 테이블에 벗어 두고 덮은 노트북 위에 팔과 머리를 올려 잠든 `/images/home/harbor-cafe-cozy-pixel-night-desk-sleep-v1.webp`, 낮 그림은 작은 부두를 제거한 `/images/home/harbor-cafe-cozy-pixel-light-clean-v1.webp`를 사용합니다. 기존 낮 원본과 빈 의자의 밤 그림을 포함한 이전 밤 그림들도 보관합니다. 밤 그림을 읽지 못하면 낮 그림과 상태 안내를 표시합니다.

`palettes.json`은 여섯 역할의 색상 기록이며, 팔레트 정보를 별도 요청으로 읽지 않도록 `preview.js`에도 같은 값을 포함합니다. 이미지 경로는 사이트 루트 기준입니다. 표시 대비값은 WCAG sRGB 상대휘도로 계산하며 본문·보조·강조를 배경과 표면 양쪽에 대조해 낮은 값을 표시합니다. 테두리는 장식 구분선이며 텍스트 대비 대상으로 계산하지 않습니다. 이 정적 자료에 대한 실제 브라우저 시각 검증은 별도로 필요합니다.
